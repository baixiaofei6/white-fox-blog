# 白小飞的个人博客

零依赖 Node 个人博客：前台像作品集一样克制、后台像写作台一样顺手。只用 Node 内置模块，`npm install` 不需要。

一个可以真正拿来做日常记录的地方：黑白极简、1260px 宽屏、公告条 + 横向导航 + 双行打字 Hero + 心形点阵粒子 + 480px 圆角海报；文章、项目、留言、评论、RSS、白天/黑夜/自动三模式都在。写作侧提供宽大正文画布、沉浸模式、编辑/预览切换、本地草稿自动保存、字数统计与快捷键，前台管理和独立后台共用同一套写作引擎。

仓库边界清楚：只含个人博客，局域网聊天项目已拆到 `baixiaofei6/super-duper-carnival`，本仓库不再混入其他项目。

## 获取

**点开即用版（推荐）**：下载 [v1.0.0 便携包](https://github.com/baixiaofei6/white-fox-blog/releases/download/v1.0.0/white-fox-blog-v1.0.0-portable.zip)，解压后双击 `白小飞的个人博客.exe` 即可，内置 Node 运行时，无需安装任何东西。

源码：`git clone https://github.com/baixiaofei6/white-fox-blog.git`

## 启动

```bash
cp config.example.json config.json   # Windows: Copy-Item config.example.json config.json
npm start                            # 或 node server.js
```

主站 <http://127.0.0.1:8787/>。管理后台是**主站同源隐藏界面** `/admin`：游客访问返回 404，只有管理员登录后才可进入。在主站「登录」输入管理员账号即可，导航出现「管理」入口。后台对文章/设置/留言/编排的任何改动都会实时同步到主站，无需刷新。
可用环境变量：`PORT`、`ADMIN_PORT`、`HOST`、`DATA_DIR`、`CONFIG_PATH`。

## 功能

- 主站：公告条、海报横幅 + 双行打字 + 高密度点阵粒子 Hero（心形装饰 + 指针散开 + 弹簧按钮）、白天/黑夜/自动三模式、图文动态、专栏、项目矩阵与分页手风琴、站点状态、链接、全员可见访客留言板、文章与评论、RSS。
- 隐藏管理后台（`/admin`，仅管理员可见）：站点文案与配色、首页模块显隐排序、文章/项目/评论/上传/用户/留言管理、改密、背景上传与自定义。与主站共用一套管理员会话，改动实时同步。
- 主站管理：导航栏「登录」用管理员账号（初始 `白小飞` / `123456`）登录，识别管理员后显示「管理」入口，可发布/编辑文章并进入隐藏管理后台。普通注册用户也能登录并在留言板自动署名。
- 只有管理员能改内容；管理员登录会话在主站同源即可调用全部管理接口（含留言删除/清空）。`config.json` 与 `data/` 不进 Git。
